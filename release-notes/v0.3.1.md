# v0.3.1 — Live Bucket Serving, Plugin System Guide

## Features

- **Buckets serve immediately after creation** — no server restart:
  - The server keeps an in-memory registry of every bucket path (public and private) and serves matching requests through the router fallback with the same transformation, caching and range semantics as before.
  - Creating a bucket through the API registers it inline: a file placed in the bucket is reachable over HTTP instantly.
  - A background reconciliation loop (`bucket_reload_interval` in `ppd_config.toml`, default `15` seconds; `0` disables it) refreshes the registry from the database, so buckets created out of band — e.g. `ppdrive bucket create` — are served within one interval.
  - Private buckets are registered too, so direct requests to them return `404` instead of falling through to an unrelated handler.
  - Bucket paths may not shadow reserved top-level routes (`/health`, `/buckets`, `/upload`, `/download`, `/auth`, `/metrics`, `/dashboard`, `/assets`); creation is rejected with `409`.
