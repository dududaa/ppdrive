PPDRIVE provides a CLI tool for managing clients, buckets, users, and file permissions.

## Usage

```sh
ppdrive [OPTIONS] <COMMAND>
```

## Commands

| Command | Description |
|---|---|
| `ppdrive serve` | Start the HTTP server |
| `ppdrive configure` | Open config file in editor |
| `ppdrive client create` | Create a new API client |
| `ppdrive client refresh` | Rotate a client's token |
| `ppdrive client list` | List all clients |
| `ppdrive bucket create` | Create a new storage bucket |
| `ppdrive user create` | Create a new user account |
| `ppdrive asset grant` | Grant file permission |
| `ppdrive asset revoke` | Revoke file permission |
| `ppdrive asset list` | List file permissions |

## Global Options

| Flag | Description |
|---|---|
| `--version` | Print version |
| `--help` | Print help |

## Command Tree

```
ppdrive
├── serve [--port <PORT>]
├── configure
├── client
│   ├── create --name <NAME>
│   ├── refresh --id <ID>
│   └── list
├── bucket
│   └── create [OPTIONS]
├── user
│   └── create --email <EMAIL> --password <PASSWORD>
└── asset
    ├── grant --bucket <PID> --path <PATH> --grantee <ID> --grantee-type <TYPE> --permission <LEVEL>
    ├── revoke --bucket <PID> --path <PATH> --grantee <ID> --grantee-type <TYPE>
    └── list --bucket <PID> --path <PATH>
```

## Examples

```sh
# Start server on custom port
ppdrive serve --port 3000

# Create a client
ppdrive client create --name "Mobile App"

# Create a private bucket
ppdrive bucket create \
  --name documents \
  --path storage/documents \
  --owner-type client \
  --owner-id <CLIENT_ID>

# Create a user
ppdrive user create --email user@example.com --password securepassword

# Grant read access to a user
ppdrive asset grant \
  --bucket <BUCKET_PID> \
  --path report.pdf \
  --grantee user@example.com \
  --grantee-type user \
  --permission read

# List file permissions
ppdrive asset list --bucket <BUCKET_PID> --path report.pdf
```
