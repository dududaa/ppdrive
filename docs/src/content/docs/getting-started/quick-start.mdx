This guide walks you through starting the server, creating a client, and uploading a file.

## 1. Start the Server

```sh
ppdrive serve
```

The server starts on port 8000 by default. You'll see tracing output in the terminal.

To use a custom port:

```sh
ppdrive serve --port 3000
```

## 2. Create a Client

In a new terminal:

```sh
ppdrive client create --name "My App"
```

Output:

```
Client created successfully!
Client ID: abc123def456...
Client Token: 7890123456...
```

Save the **Client Token** — you'll need it for all API requests.

## 3. Create a Bucket

```sh
ppdrive bucket create \
  --name media \
  --path uploads/media \
  --owner-type client \
  --owner-id abc123def456...
```

Replace `abc123def456...` with your Client ID from the previous step.

Output:

```
Bucket created successfully!
Bucket ID: xyz789...
```

## 4. Upload a File

### Step 1: Create an upload session

<Tabs>
<TabItem label="JavaScript">

```js
const CLIENT_TOKEN = "7890123456...";
const BUCKET_ID = "xyz789...";

const res = await fetch("http://localhost:8000/upload/session", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-ppdrive-client": CLIENT_TOKEN,
  },
  body: JSON.stringify({
    asset_type: "File",
    path: "uploads/media/photo.jpg",
    target_filesize: 102400,
    expires: 120,
    bucket: BUCKET_ID,
    content_type: "image/jpeg",
  }),
});

const { data: token } = await res.json();
```

</TabItem>
<TabItem label="curl">

```sh
curl -X POST http://localhost:8000/upload/session \
  -H "Content-Type: application/json" \
  -H "x-ppdrive-client: 7890123456..." \
  -d '{
    "asset_type": "File",
    "path": "uploads/media/photo.jpg",
    "target_filesize": 102400,
    "expires": 120,
    "bucket": "xyz789...",
    "content_type": "image/jpeg"
  }'
```

</TabItem>
</Tabs>

Replace `7890123456...` with your Client Token and `xyz789...` with your Bucket ID.

Response:

```json
{
  "data": "eyJ0eXAiOiJKV1..."
}
```

Save the token from the `data` field.

### Step 2: Upload the file

<Tabs>
<TabItem label="JavaScript">

```js
const token = "eyJ0eXAiOiJKV1..."; // from Step 1
const file = document.querySelector("input[type=file]").files[0];

const res = await fetch(`http://localhost:8000/upload/session/play/${token}`, {
  method: "POST",
  body: file,
});

const { data } = await res.json();
// data is null when complete, or a new token for resumable uploads
```

</TabItem>
<TabItem label="curl">

```sh
curl -X POST "http://localhost:8000/upload/session/play/eyJ0eXAiOiJKV1..." \
  --data-binary @/path/to/photo.jpg
```

</TabItem>
</Tabs>

Replace the token with the one from Step 1.

Response:

```json
{
  "data": null
}
```

## 5. Download the File

### Public Bucket

If the bucket is public, the file is accessible directly:

<Tabs>
<TabItem label="JavaScript">

```js
const res = await fetch("http://localhost:8000/uploads/media/photo.jpg");
const blob = await res.blob();
```

</TabItem>
<TabItem label="curl">

```sh
curl http://localhost:8000/uploads/media/photo.jpg
```

</TabItem>
</Tabs>

### Private Bucket

For private buckets, generate a signed download URL:

<Tabs>
<TabItem label="JavaScript">

```js
const CLIENT_TOKEN = "7890123456...";
const BUCKET_ID = "xyz789...";

// Step 1: Sign the download
const signRes = await fetch("http://localhost:8000/download/sign", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-ppdrive-client": CLIENT_TOKEN,
  },
  body: JSON.stringify({
    path: "photo.jpg",
    bucket: BUCKET_ID,
    expires: 300,
  }),
});

const { data: token } = await signRes.json();

// Step 2: Download using the token
const fileRes = await fetch(`http://localhost:8000/download/${token}`);
const blob = await fileRes.blob();
```

</TabItem>
<TabItem label="curl">

```sh
# Step 1: Sign the download
curl -X POST http://localhost:8000/download/sign \
  -H "Content-Type: application/json" \
  -H "x-ppdrive-client: 7890123456..." \
  -d '{
    "path": "photo.jpg",
    "bucket": "xyz789...",
    "expires": 300
  }'

# Step 2: Download using the token
curl "http://localhost:8000/download/eyJ0eXAiOiJKV1..."
```

</TabItem>
</Tabs>

## Uploading to a Folder (No Bucket)

You can upload directly to a path without a bucket, but only if the path starts with a [configured static directory](/configuration/config-file/#static-folders) in `ppd_config.toml`. For example, with the default config:

```toml
[[static_folders]]
name = "uploads"
```

You can upload to `uploads/documents/report.pdf` without a bucket. Uploading to a path like `other/report.pdf` (not under a configured static directory) will fail.

When uploading without a bucket, you must specify which MIME types are allowed via the `accepts` field:

<Tabs>
<TabItem label="JavaScript">

```js
// Create session
const sessionRes = await fetch("http://localhost:8000/upload/session", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-ppdrive-client": CLIENT_TOKEN,
  },
  body: JSON.stringify({
    asset_type: "File",
    path: "uploads/documents/report.pdf",
    target_filesize: 204800,
    expires: 120,
    accepts: ["application/pdf"],
  }),
});

const { data: token } = await sessionRes.json();

// Upload file
await fetch(`http://localhost:8000/upload/session/play/${token}`, {
  method: "POST",
  body: file,
});
```

</TabItem>
<TabItem label="curl">

```sh
# Create session
curl -X POST http://localhost:8000/upload/session \
  -H "Content-Type: application/json" \
  -H "x-ppdrive-client: 7890123456..." \
  -d '{
    "asset_type": "File",
    "path": "uploads/documents/report.pdf",
    "target_filesize": 204800,
    "expires": 120,
    "accepts": ["application/pdf"]
  }'

# Upload file
curl -X POST "http://localhost:8000/upload/session/play/<token>" \
  --data-binary @/path/to/report.pdf
```

</TabItem>
</Tabs>
