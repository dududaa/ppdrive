PPDRIVE is configured via a TOML file at the project root. Use `ppdrive configure` to open it in your editor.

## File Location

The config file is `ppd_config.toml` in the same directory as the PPDRIVE binaries.

## Configuration Reference

```toml
# Database connection URL (required)
# Supports: sqlite:path, postgres://..., mysql://...
database_url = "sqlite:data.db"

# HTTP header name used for client authentication (required)
client_header_key = "x-ppdrive-client"

# Server listen port (optional, default: 8000)
port = 8000

# Maximum database connections in the pool (optional, default: 10)
# db_pool_size = 10

# CORS allowed origins (optional, default: allow all)
# Set to null or omit to allow all origins
allowed_origins = ["https://example.com", "https://app.example.com"]

# Subdirectory for file storage relative to the binary (optional)
# Default: binary directory
root_dir = "storage"

# Redis URL for resumable uploads and transformed-download caching (optional)
# Required only if you need resumable upload support or a server-side
# cache for on-the-fly image transformations
message_broker = "redis://localhost:6379"

# Hashing algorithm for signed tokens (required)
# Options: "HMAC256" or "Blake3"
hasher = "Blake3"

# Whether image conversion runs after the upload response (optional, default: false)
# false = convert inline before the upload completes
# The per-upload image_conversion.background option overrides this
# image_conversion_background = true

# Whether image transformation runs after the upload response (optional, default: false)
# false = transform inline before the upload completes
# The per-upload image_transformation.background option overrides this
# image_transformation_background = true

# Whether audio conversion runs after the upload response (optional, default: false)
# false = convert inline before the upload completes
# The per-upload audio_conversion.background option overrides this
# audio_conversion_background = true

# Whether audio effects run after the upload response (optional, default: false)
# false = process inline before the upload completes
# The per-upload audio_effects.background option overrides this
# audio_effects_background = true

# Whether media streaming packaging runs after the upload response
# (optional, default: false). false = package inline before the upload
# completes. The per-upload media_streaming.background option overrides this
# media_streaming_background = true

# Server-side cache TTL for transformed download responses in seconds
# (optional, default: 86400). Requires message_broker; 0 disables the cache
# transform_cache_ttl_secs = 86400

# Cache-Control max-age for transformed download responses in seconds
# (optional, default: 3600)
# transform_cache_max_age_secs = 3600

# Static file directories to serve (optional)
# Files are served at /{name} by default, or at a custom path
[[static_folders]]
name = "uploads"

[[static_folders]]
name = "public"
path = "/static"
```

## Field Reference

| Field | Type | Default | Description |
|---|---|---|---|
| `database_url` | `String` | — | Database connection URL (required) |
| `client_header_key` | `String` | `x-ppdrive-client` | HTTP header for client authentication |
| `port` | `u16` | `8000` | Server listen port |
| `allowed_origins` | `Vec<String>` | `null` (all) | CORS origin whitelist. When `null`, all origins are permitted and a warning is logged at startup |
| `root_dir` | `String` | `null` (binary dir) | Storage subdirectory. The SQLite database file also resolves against this directory, not the current working directory |
| `db_pool_size` | `u32` | `10` | Max database connections in pool |
| `message_broker` | `String` | `null` | Redis URL for resumable uploads and server-side caching of transformed download responses |
| `hasher` | `String` | `HMAC256` | Hash algorithm: `HMAC256` or `Blake3` |
| `image_conversion_background` | `bool` | `false` | Whether image conversion runs after the upload response instead of inline. The per-upload `image_conversion.background` option overrides this |
| `image_transformation_background` | `bool` | `false` | Whether image transformation runs after the upload response instead of inline. The per-upload `image_transformation.background` option overrides this. If either processing option requests background, the whole transform → convert chain runs after the response |
| `audio_conversion_background` | `bool` | `false` | Whether audio conversion runs after the upload response instead of inline. The per-upload `audio_conversion.background` option overrides this |
| `audio_effects_background` | `bool` | `false` | Whether audio effects run after the upload response instead of inline. The per-upload `audio_effects.background` option overrides this. If either audio option requests background, the whole effects → convert chain runs after the response |
| `media_streaming_background` | `bool` | `false` | Whether media streaming packaging runs after the upload response instead of inline. The per-upload `media_streaming.background` option overrides this. If any post-processing option requests background, the whole process → rename → package → register chain runs after the response |
| `transform_cache_ttl_secs` | `u64` | `86400` | Server-side cache TTL (seconds) for transformed download responses, stored in the message broker. `0` disables server-side caching; without `message_broker` every transformed request runs the plugin |
| `transform_cache_max_age_secs` | `u64` | `3600` | `Cache-Control: max-age` (seconds) advertised on transformed download responses. For signed downloads the value is capped at the token's remaining lifetime |
| `static_folders` | `Array` | `[]` | Directories to serve as static files |

## Static Folders

Each `[[static_folders]]` entry has:

| Field | Type | Description |
|---|---|---|
| `name` | `String` | Directory name on disk |
| `path` | `String` | URL mount point (defaults to `/{name}`) |

Example: A folder named `uploads` served at `/media`:

```toml
[[static_folders]]
name = "uploads"
path = "/media"
```

## Minimal Configuration

The only required field is `database_url`. Everything else has sensible defaults:

```toml
database_url = "sqlite:data.db"
```

## Full Example

```toml
database_url = "postgres://user:pass@localhost:5432/ppdrive"
client_header_key = "x-api-key"
port = 3000
db_pool_size = 20
allowed_origins = ["https://myapp.com"]
root_dir = "data"
message_broker = "redis://localhost:6379"
hasher = "Blake3"

[[static_folders]]
name = "uploads"
path = "/files"

[[static_folders]]
name = "public"
```

## Environment Variables

- `RUST_LOG` — Controls tracing verbosity (default: `trace`)
- `PPDRIVE_DATABASE_URL` — Can override `database_url` at runtime (used in Docker)
