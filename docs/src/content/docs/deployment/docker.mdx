PPDRIVE provides Docker images and a Docker Compose setup for easy deployment.

## Quick Start with Docker Compose

```sh
git clone https://github.com/dududaa/ppdrive.git
cd ppdrive
docker compose up -d
```

This starts:
- **ppdrive** — The server on port 8000
- **ppdrive_db** — PostgreSQL database
- **ppdrive_redis** — Redis for resumable uploads

## Docker Compose Configuration

```yaml
services:
  ppdrive_redis:
    image: redis:7-alpine
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 5

  ppdrive_db:
    image: postgres:17-alpine
    environment:
      POSTGRES_USER: ppdrive_user
      POSTGRES_PASSWORD: your_secure_password_here
      POSTGRES_DB: ppdrive
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ppdrive_user -d ppdrive"]
      interval: 5s
      timeout: 5s
      retries: 5

  ppdrive:
    image: dududaa/ppdrive:latest
    ports:
      - "8000:8000"
    environment:
      PPDRIVE_DATABASE_URL: postgres://ppdrive_user:your_secure_password_here@ppdrive_db:5432/ppdrive
    depends_on:
      ppdrive_db:
        condition: service_healthy
      ppdrive_redis:
        condition: service_healthy
    volumes:
      - ppdrive_data:/app/data

volumes:
  postgres_data:
  ppdrive_data:
```

## Environment Variables

| Variable | Description |
|---|---|
| `PPDRIVE_DATABASE_URL` | Database connection URL (overrides config file) |

## Standalone Docker

### Build the Image

```sh
docker build -t ppdrive .
```

### Run the Container

```sh
docker run -p 8000:8000 ppdrive
```

### With Volume Mounts

```sh
docker run -p 8000:8000 \
  -v ppdrive_data:/app/data \
  -e PPDRIVE_DATABASE_URL=sqlite:/app/data/data.db \
  ppdrive
```

## Dockerfile

The Dockerfile uses a multi-stage build:

```dockerfile
# Builder stage
FROM rust:1.83 AS builder
WORKDIR /app
COPY . .
RUN cargo build --release

# Runtime stage
FROM debian:bookworm-slim
RUN apt-get update && apt-get install -y libpq-dev libssl3 ca-certificates curl
RUN groupadd -r ppdrive && useradd -r -g ppdrive -d /app ppdrive
WORKDIR /app
COPY --from=builder /app/target/release/ppdrive /usr/local/bin/ppdrive
COPY --from=builder /app/target/release/server /usr/local/bin/server
COPY --from=builder /app/migrations ./migrations
RUN chown -R ppdrive:ppdrive /app
USER ppdrive
EXPOSE 8000
CMD ["server"]
```

## Production Docker Compose

For production, create a `docker-compose.prod.yml`:

```yaml
services:
  ppdrive_redis:
    image: redis:7-alpine
    restart: always
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 5

  ppdrive_db:
    image: postgres:17-alpine
    environment:
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
      POSTGRES_DB: ppdrive
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: always
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U $${DB_USER} -d ppdrive"]
      interval: 5s
      timeout: 5s
      retries: 5

  ppdrive:
    image: dududaa/ppdrive:latest
    ports:
      - "8000:8000"
    environment:
      PPDRIVE_DATABASE_URL: postgres://${DB_USER}:${DB_PASSWORD}@ppdrive_db:5432/ppdrive
    depends_on:
      ppdrive_db:
        condition: service_healthy
      ppdrive_redis:
        condition: service_healthy
    volumes:
      - ppdrive_data:/app/data
    restart: always

volumes:
  postgres_data:
  ppdrive_data:
```

Create a `.env` file:

```bash
DB_USER=ppdrive_user
DB_PASSWORD=your_secure_password_here
```

```sh
docker compose -f docker-compose.prod.yml up -d
```

## Networking

When running in Docker, services communicate via the Docker network. Use the service name as the hostname:

- Database: `ppdrive_db`
- Redis: `ppdrive_redis`

## Volumes

| Volume | Mount Point | Purpose |
|---|---|---|
| `ppdrive_data` | `/app/data` | Uploaded files and data |
| `postgres_data` | `/var/lib/postgresql/data` | PostgreSQL data |

## Troubleshooting

### Container exits immediately

Check logs:

```sh
docker compose logs ppdrive
```

Common issues:
- Database connection refused (check `ppdrive_db` is running)
- Invalid `PPDRIVE_DATABASE_URL`

### Database connection refused

Ensure the database container is healthy:

```sh
docker compose ps
docker compose logs ppdrive_db
```

### Permission denied on secrets file

The container runs as the `ppdrive` user. The secrets file and data directory are owned by this user. If you mount a host directory, ensure it is writable by uid `ppdrive` (typically uid 100 in the container).
