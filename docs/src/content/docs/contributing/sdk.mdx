PPDRIVE works with any language that can send HTTP requests. We encourage developers to build client SDKs for their favorite languages and share them with the community.

## Overview

A PPDRIVE client SDK wraps the HTTP API in a native-language client class. The SDK handles client token authentication, request formatting, error handling, and the two-step upload/download flows — so users of your SDK don't need to manage these details.

## Step 1: Read the SDK Specification

The [SDK Specification](https://github.com/dududaa/ppdrive/blob/main/SDK_SPEC.md) defines:

- **Client class** — Constructor, options, methods
- **10 API methods** — Upload, download, signed URLs, buckets, permissions
- **Type definitions** — Request/response shapes
- **Error handling** — Status code mapping and error classes
- **Resumable uploads** — Chunking flow and resume support
- **Range downloads** — Partial file downloads
- **Naming conventions** — How to adapt to your language's style

### API Methods

Implement these methods based on the SDK specification:

| Method | Description |
|--------|-------------|
| `uploadFile(path, data, options?)` | Upload a file (two-step: session + data). |
| `uploadFolder(path, options?)` | Create a folder. |
| `signUploadUrl(path, options?)` | Generate a signed upload URL (returns URL, does not upload). |
| `downloadFile(bucketPid, path, options?)` | Download from a private bucket (two-step: sign + fetch). |
| `downloadPublicFile(url)` | Download from a public bucket (direct HTTP). |
| `signDownloadUrl(bucketPid, path, options?)` | Generate a signed download URL (returns URL, does not download). |
| `createBucket(options)` | Create a storage bucket. |
| `grantPermission(bucketPid, options)` | Grant file-level permission. |
| `revokePermission(bucketPid, options)` | Revoke file-level permission. |
| `listPermissions(bucketPid, path?)` | List file permissions. |

### Two-Step Upload Flow

The upload is a two-step process. Your SDK should handle this internally:

<Tabs>
<TabItem label="JavaScript">

```javascript
async uploadFile(path, data, options = {}) {
  // Step 1: Create session
  const sessionRes = await this._request("POST", "/upload/session", {
    asset_type: "File",
    path,
    target_filesize: data.length,
    expires: options.expires || 120,
    bucket: options.bucket,
    content_type: options.contentType,
    overwrite: options.overwrite || false,
    create_parents: options.createParents || false,
    resumable: options.resumable || false,
  });

  const token = sessionRes.data;

  // Step 2: Upload data
  await this._request("POST", `/upload/session/play/${token}`, data, {
    raw: true,
  });
}
```

</TabItem>
<TabItem label="Python">

```python
def upload_file(self, path, data, **options):
    # Step 1: Create session
    session_res = self._request("POST", "/upload/session", {
        "asset_type": "File",
        "path": path,
        "target_filesize": len(data),
        "expires": options.get("expires", 120),
        "bucket": options.get("bucket"),
        "content_type": options.get("content_type"),
        "overwrite": options.get("overwrite", False),
        "create_parents": options.get("create_parents", False),
        "resumable": options.get("resumable", False),
    })

    token = session_res["data"]

    # Step 2: Upload data
    self._request("POST", f"/upload/session/play/{token}", data, raw=True)
```

</TabItem>
</Tabs>

### Two-Step Download Flow

The private bucket download is also two steps:

<Tabs>
<TabItem label="JavaScript">

```javascript
async downloadFile(bucketPid, path, options = {}) {
  // Step 1: Sign the download
  const signRes = await this._request("POST", "/download/sign", {
    path,
    bucket: bucketPid,
    expires: options.expires || 300,
  });

  const token = signRes.data;

  // Step 2: Download the file
  return this._request("GET", `/download/${token}`, null, {
    raw: true,
    range: options.range,
  });
}
```

</TabItem>
<TabItem label="Python">

```python
def download_file(self, bucket_pid, path, **options):
    # Step 1: Sign the download
    sign_res = self._request("POST", "/download/sign", {
        "path": path,
        "bucket": bucket_pid,
        "expires": options.get("expires", 300),
    })

    token = sign_res["data"]

    # Step 2: Download the file
    return self._request("GET", f"/download/{token}", raw=True,
                         range_header=options.get("range"))
```

</TabItem>
</Tabs>

### Error Handling

Define a typed error class and map HTTP status codes:

```javascript
class PPDRIVEError extends Error {
  constructor(status, message) {
    super(message);
    this.name = "PPDRIVEError";
    this.status = status;
  }
}
```

| Status | Error Name |
|--------|-----------|
| 400 | `ValidationError` |
| 401 | `AuthenticationError` |
| 403 | `AuthorizationError` |
| 404 | `NotFoundError` |
| 409 | `ConflictError` |
| 413 | `PayloadTooLargeError` |
| 416 | `RangeError` |
| 429 | `RateLimitError` |
| 500 | `ServerError` |

### Internal HTTP Client

Your SDK should have a thin HTTP client wrapper that:

- Sets the `x-ppdrive-client` header with the client token
- Sends JSON for request bodies
- Parses `{"data": ...}` responses
- Throws `PPDRIVEError` on non-2xx responses
- Supports raw binary responses for uploads/downloads

## Step 4: Write Tests

Include both unit and integration tests:

### Unit Tests

Mock HTTP responses and verify:
- Correct headers are sent
- Request bodies are formatted correctly
- Responses are parsed into the right types
- Errors are thrown for bad status codes

### Integration Tests

Run against a live PPDRIVE server:

```bash
# Start test server
ppdrive serve --port 8000 &

# Create test client
ppdrive client create --name "SDK Tests"

# Run tests with the token
TEST_TOKEN="..." npm test
```

Test the full flow:
1. Create a bucket
2. Upload a file
3. Download the file
4. Grant permission to another client
5. Verify the other client can download
6. Revoke permission
7. Verify access is denied

## Naming Conventions

| Concept | JavaScript | Python | Go | Rust |
|---------|-----------|--------|----|------|
| Class | `PPDRIVEClient` | `PPDRIVEClient` | `Client` | `Client` |
| Methods | `camelCase` | `snake_case` | `PascalCase` | `snake_case` |
| Error | `PPDRIVEError` | `PPDRIVEError` | `*Error` | `Error` |
| Options | `UploadOptions` | `UploadOptions` | `UploadOpts` | `UploadOptions` |
