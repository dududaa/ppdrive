Buckets are isolated storage containers with their own path, size limits, and MIME restrictions. Each bucket is owned by a client and identified by a unique PID.

## Create a Bucket

<Tabs>
<TabItem label="JavaScript">

```js
const CLIENT_TOKEN = "YOUR_TOKEN";

const res = await fetch("http://localhost:8000/buckets", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-ppdrive-client": CLIENT_TOKEN,
  },
  body: JSON.stringify({
    name: "photos",
    path: "/buckets/photos",
    public: false,
    size: 1024,
    accepts: ["image/*"],
  }),
});

// 201 Created
const { data: bucketPid } = await res.json();
// bucketPid = "a1b2c3d4..."
```

</TabItem>
<TabItem label="curl">

```sh
curl -X POST http://localhost:8000/buckets \
  -H "Content-Type: application/json" \
  -H "x-ppdrive-client: YOUR_TOKEN" \
  -d '{
    "name": "photos",
    "path": "/buckets/photos",
    "public": false,
    "size": 1024,
    "accepts": ["image/*"]
  }'
```

</TabItem>
</Tabs>

### Request Body

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `name` | `String` | Yes | — | Human-readable bucket name (1–255 chars) |
| `path` | `String` | Yes | — | Storage path relative to root directory (must not be empty) |
| `public` | `bool` | No | `false` | Whether the bucket is publicly readable |
| `size` | `i64` | No | `null` | Maximum bucket size in megabytes (`null` = unlimited) |
| `accepts` | `String[]` | No | `null` | Accepted MIME types (e.g. `["image/*", "application/pdf"]`) |

### Response

**`201 Created`**

```json
{
  "data": "a1b2c3d4e5f6..."
}
```

The `data` field contains the bucket's public PID — use it for upload/download operations.

### Validation Rules

- `name` must be 1–255 characters
- `path` must not be empty
- `path` must not contain `..` (path traversal)
- Bucket path must not conflict with a [static folder](/configuration/config-file/#static-folders)
- Private buckets cannot be created inside public buckets
- The client must own all parent paths

### Error Responses

| Status | Message | Cause |
|---|---|---|
| 400 | `path must not be empty` | Empty path provided |
| 400 | `path contains invalid components: '..' is not allowed` | Path traversal attempt |
| 400 | Validation error | Name too long, path empty, etc. |
| 401 | `missing client header key` | No auth header |
| 401 | `client verification failed` | Invalid or expired token |
| 403 | `Bucket parent(s) is owned by a different entity...` | Path overlaps another client's bucket |
| 409 | `Bucket path '...' conflicts with static folder...` | Path crosses a configured static folder |

## Upload to a Bucket

Once you have a bucket PID, use it when creating an upload session:

```js
const res = await fetch("http://localhost:8000/upload/session", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-ppdrive-client": CLIENT_TOKEN,
  },
  body: JSON.stringify({
    asset_type: "File",
    path: "photo.jpg",
    target_filesize: 102400,
    expires: 120,
    bucket: bucketPid,
    content_type: "image/jpeg",
  }),
});
```

See [Upload Flow](/api/upload/) for full details.

## Download from a Bucket

For private buckets, sign a download URL first:

```js
const signRes = await fetch("http://localhost:8000/download/sign", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-ppdrive-client": CLIENT_TOKEN,
  },
  body: JSON.stringify({
    path: "photo.jpg",
    bucket: bucketPid,
    expires: 300,
  }),
});

const { data: token } = await signRes.json();
const fileRes = await fetch(`http://localhost:8000/download/${token}`);
```

For public buckets, files are served directly at the bucket path. See [Download Flow](/api/download/) for full details.
