PPDRIVE is a self-hosted object storage service built with Rust. It provides an S3-like API for uploading, storing, and downloading files, with support for public and private buckets, signed URLs, resumable uploads, and MIME type validation.

## Key Features

- **Upload & Download** — Simple two-step upload flow with signed session tokens. Range-header support for efficient downloads.
- **Public & Private Buckets** — Public buckets serve files directly. Private buckets require signed URLs for access.
- **Resumable Uploads** — Chunk large files with automatic retry. Redis-backed session state preserves progress across interruptions.
- **MIME Validation** — Buckets can restrict accepted file types with exact or wildcard patterns (e.g., `image/*`).
- **Client Authentication** — XChaCha20-Poly1305 encrypted client tokens. Keys stored encrypted at rest.
- **Multiple Databases** — SQLite (default, zero-config), PostgreSQL, or MySQL.
- **Cross-Platform** — Pre-built binaries for Linux, macOS, and Windows. Docker support included.

## Use Cases

- **Application file storage** — Store user uploads, avatars, documents
- **Media serving** — Serve images and videos with Content-Type detection
- **Backup storage** — Resumable uploads for large backup files
- **Development** — Local object storage for testing without cloud dependencies

## How It Works

1. Start the server with `ppdrive serve`
2. Create a client with `ppdrive client create --name "My App"`
3. Create a bucket with `ppdrive bucket create --name media --path uploads/media --owner-type client --owner-id <ID>`
4. Upload files via the HTTP API using the client token
5. Download files directly (public buckets) or via signed URLs (private buckets)
