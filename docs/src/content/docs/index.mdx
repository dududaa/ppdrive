## What is PPDRIVE?

PPDRIVE is a self-hosted object storage service that lets you deploy a fully functional remote file storage system in minutes. It provides an S3-compatible API for uploading, storing, and downloading files — giving you the same capabilities as commercial cloud storage services like Amazon S3, without the vendor lock-in or recurring costs.

Whether you're building a web application that needs file uploads, serving media assets, or running a development environment that requires local object storage, PPDRIVE gives you full control over your data and infrastructure.

## Why PPDRIVE?

- **Language Agnostic** — Works with any programming language or framework that sends HTTP requests. JavaScript, Python, Go, Rust, Flutter — you name it.
- **Privacy and Data Control** — All your data stays on your server. PPDRIVE does not collect, transmit, or monetize your data in any way.
- **No Vendor Lock-in** — Open source and free forever. Migrate away at any time with zero friction.
- **User-Level Authorization** — Fine-grained resource ownership ensures only authorized clients can access specific buckets and files.
- **Cross-Platform** — Runs on Linux, macOS, and Windows. Pre-built binaries for x86_64 and ARM64. Docker support included.
- **Lightweight** — Single binary. SQLite by default. No JVM, no Node.js runtime, no external dependencies required.

## Quick Start

Install PPDRIVE and have your object storage running in three commands:

```bash
# Install (Linux/macOS)
curl -fsSL https://raw.githubusercontent.com/dududaa/ppdrive/main/install.sh | bash

# Create a client
ppdrive client create --name myapp --max-bucket-size 100

# Start the server
ppdrive serve
```

That's it. Your storage API is now available at `http://localhost:8000`. Upload files using the client token from any HTTP-capable application.
